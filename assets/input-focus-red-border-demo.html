Voiceflow Widget: Input Focus Ring Color

The focus ring is created by .vfrc-chat-focus-ring using an inset box-shadow.

Default (Blue)

.vfrc-chat-focus-ring { box-shadow: rgb(57, 125, 255) 0px 0px 0px 2px inset; }

Custom (Red)

.vfrc-chat-focus-ring { box-shadow: #e53935 0px 0px 0px 2px inset !important; }

Key Finding

The focus ring is NOT on .vfrc-input-container itself. It's a separate absolutely-positioned overlay element called .vfrc-chat-focus-ring.
